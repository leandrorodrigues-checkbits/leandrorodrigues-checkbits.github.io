Site para Prospecção de Empresas no Web Summit
CHECKBITS SCOUT | WEB SUMMIT LISBOA 2026

QUICK START
1. Simplest: open Checkbits_WS26_Prospeccao_Mobile.html in a normal mobile browser.
2. Best mobile experience: upload the contents of this ZIP to a static HTTPS host (for example Netlify Drop or GitHub Pages). The site can then be added to your phone's home screen and can work offline after first visit.
3. All contact statuses, dates and notes save automatically on the device/browser using localStorage. They do NOT sync between devices.
4. To move or back up your updates: in the app, open Dados > Exportar backup JSON; import it on the destination device.
5. CSV export captures the updated entire lead list.
6. Do not use private/incognito tabs or clear browser site data.

DATA LIMITATIONS
- 297 registration entries from 50 screenshots; European Commission may repeat.
- The scoring is an initial strategic ranking, not a prediction of purchase intention.
- Confidence relates to the company identification, not probability of conversion.
- Recommended people are job functions, not confirmed stand attendees.
- When a verified company site cannot be identified, the app offers a web search instead.
- No login, cloud server, or cross-device sync is included.
